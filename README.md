# PMC – Energy Advisory

Site institucional da PMC Energy Advisory, empresa de engenharia e consultoria eletrotécnica em Lisboa.

## Ver o site

https://nuninhopedro234-gif.github.io/pmc-site/

## Estrutura do projeto

- `index.html` – página principal do site (contém o HTML, o CSS via Tailwind e o JavaScript).

## Como atualizar o site

1. Abre o ficheiro `index.html` no GitHub.
2. Clica no ícone de lápis (*Edit this file*).
3. Faz as alterações e clica em **Commit changes**.
4. Aguarda 1 a 2 minutos e atualiza a página.

## Tecnologias

- HTML5
- Tailwind CSS (via CDN)
- Google Fonts
